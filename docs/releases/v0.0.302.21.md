# Codegraff v0.0.302.21

This release makes graff work on Windows from start to finish, without WSL,
and smooths the two sign-ins people hit most.

## Install on Windows

In PowerShell:

```powershell
irm https://codegraff.com/install.ps1 | iex
```

The installer picks the x86_64 or ARM64 build, checks it against the release's
`SHA256SUMS`, installs `graff.exe` under `%LOCALAPPDATA%\Programs\graff\bin`
and adds that folder to your user `PATH`. Open a new terminal and run
`graff login`. Running `install.sh` from Git Bash now points you to the
PowerShell installer and stops. It used to suggest WSL2 and then try to build
from source.

## `graff login` works when the browser doesn't open

`graff login` used to print `https://codegraff.com/cli/auth` and a code, and
open the browser only with the code-carrying link. On Windows the browser
never opened, and the printed link led to a page with nowhere to enter the
code. graff now prints the link with the code in it, and opens the browser on
Windows. The approval page also accepts a typed code, for older versions.

## An expired ChatGPT sign-in no longer ends the turn

ChatGPT sign-ins currently last about an hour, because renewals are refused
upstream for every client. When one lapses in an interactive session, graff
opens the browser sign-in, waits up to three minutes and retries the request
with the new token. `-p`, piped and `--json` runs, ACP sessions and sub-agents
never open a browser
([ADR 0253](https://github.com/justrach/codegraff/blob/v0.0.302.21/docs/adr/0253-an-interactive-session-signs-in-to-chatgpt-again.md)).
