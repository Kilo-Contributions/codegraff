# Codegraff v0.0.302.22

This release lets you continue your Claude Code conversations in graff.

## Bring your Claude Code conversations to `/resume`

`/import-claude` (or `graff mcp import`) already copied your Claude Code and
Cursor MCP servers, skills, hooks and rules. It now also imports the current
project's Claude Code conversations, so `/resume` lists them next to your graff
sessions:

```sh
graff mcp import                      # setup + every conversation in this project
graff mcp import-session <session-id> # just one conversation, no setup
```

An import keeps the dialogue, tool calls and their results, titles, timestamps
and the model the conversation used. Signed thinking and sub-agent sidechains
are left out. Saves are named `claude-<session-id>`, and importing again never
overwrites a save you already have.

## Imports continue on your graff provider

A resumed import runs on the provider and credentials graff is configured with,
not the route the conversation came from. The source model is kept as history.
When the wire format differs, earlier tool calls and results come through as
labeled text receipts, so the model still sees what happened. Importing never
reads Claude credentials, and no imported tool call runs again
([ADR 0254](https://github.com/justrach/codegraff/blob/v0.0.302.22/docs/adr/0254-imported-conversations-use-the-configured-route.md)).
