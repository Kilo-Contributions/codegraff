# Codegraff v0.0.302.27

Choose where automatic compaction starts.

## The compaction point is yours to set

graff compacts a conversation once it fills 80% of the model's context window.
You can now move that point anywhere from 10% to 95%. Lower keeps each request
smaller and cheaper; higher keeps more of the conversation word for word.

- In a chat, `/compact-at 70` applies at once and is saved for the workspace.
  `/compact-at` shows the current point, and `/compact-at default` goes back
  to 80%. This works in the terminal and in the desktop app.
- From the command line, use `graff --compact-at 70`. From code, pass
  `compactAt: 70` to the TypeScript SDK or `compact_at=70` to the Python SDK.
- `GRAFF_COMPACT_PCT=70` works as before. The desktop app's new setting
  (Settings → Agents → Graff compaction point) uses it.

The command-line flag wins over the environment variable, which wins over a
value saved with `/compact-at`.
