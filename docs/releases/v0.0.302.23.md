# Codegraff v0.0.302.23

A hotfix for prompt caching on the ChatGPT-plan sign-in.

## The ChatGPT-plan sign-in caches again

Since every ChatGPT login moved to the `chatgpt-new` sign-in, its requests
carried the cache key in the body but not the matching `session_id` header,
which graff only sent on the `codex` route. Without it, those requests were
not read from the prompt cache, so every turn paid for the full context.

graff now sends `session_id` on both the HTTP and WebSocket requests of the
`chatgpt-new` route, for every model on it, set to the same value as the
request's cache key (child agents included). The Codex-only identity headers
still go to `codex` only.
