# Codegraff v0.0.302.28

See which graff sent each request.

## Version and device on every request

Requests to the Codegraff gateway now carry the graff version that sent them,
the device they came from and the app that launched graff. The usage page on
codegraff.com shows all three on each request, so you can tell at a glance
whether a machine is still on an old build.

- The version is sent as `User-Agent: graff/<version>`.
- The device is the computer's hostname. A launcher can pass its own name for
  the computer with `GRAFF_DEVICE_NAME`; the desktop app does this.
- The app comes from `GRAFF_HOST_APP`, which the desktop app sets to its own
  version.

Set `GRAFF_CLIENT_TAGS=off` to send neither the device nor the app; the
version still goes. Requests to other providers carry none of these headers.
